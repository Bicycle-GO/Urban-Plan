# Urban-Plan

도시계획기사 1차 필기와 3차 실기 대비 학습을 함께 진행할 수 있는 웹 학습 페이지입니다. 2003~2022년 59개 필기 회차(5,900문항)와 2022년 4회 공유대화 보강문제를 CBT처럼 풀 수 있으며, 모든 문항에 이 프로젝트를 위해 독립적으로 작성한 문항별 상세해설과 한 줄 암기가 포함됩니다.

## 구성

- `index.html`: 빌드 도구 없이 바로 열 수 있는 학습 페이지 진입 파일
- `styles.css`: 반응형 레이아웃과 화면 스타일
- `app.js`: CBT 채점, 타이머, 번호판, 진도 저장, 강의 콘텐츠와 도면 렌더링
- `data/`: 59개 회차 문항·정답 아카이브, 5,900개 문항별 상세해설, 2022년 4회 보강문제 데이터
- `app/`: 게시용 Sites/Next.js 진입 화면
- `tools/build-exam-data.ps1`: 공개 기출 문항·보기·정답만 다시 구조화하는 데이터 생성 도구

## 사용 방법

브라우저에서 `index.html` 파일을 열면 바로 사용할 수 있습니다.

학습 진도, 문제 풀이, 실기 체크리스트는 브라우저의 `localStorage`에 저장됩니다.

게시용 미리보기는 `pnpm install` 후 `pnpm run dev`, 최종 빌드는 `pnpm run build`로 생성합니다.

## 자료 안내

- 문항과 정답: COMCBT 도시계획기사 자료실의 2003~2022년 59개 공개 기출 회차
- 2022년 4회 보강: 사용자 제공 공유 대화의 학습 주제와 관련 공개 기출 10문항, 재구성 2문항, 도보권 근린공원 법규 1문항
- 전체 해설: 5,900문항마다 정답이 성립하는 이유와 핵심 개념을 독립적으로 작성
- 문항별 보강: 계산형은 공식·대입·단위, 법규형은 출제 당시 기준, 개념형은 헷갈리는 선택지와의 차이를 설명
- 안전 안내: 오류 신고·복원 문항은 별도 경고, 법규 문항은 회차별 출제 연도 기준을 표시
- 법규: 각 회차 출제 당시 기준이므로 최신 조문은 Q-Net 및 국가법령정보센터에서 별도 확인 필요
