# Urban-Plan

도시계획기사 1차 필기와 3차 실기 대비 학습을 함께 진행할 수 있는 웹 학습 페이지입니다. 2022년 제1회 필기 100문항을 실제 CBT처럼 풀고, 이 프로젝트를 위해 독립적으로 작성한 해설을 확인할 수 있습니다.

## 구성

- `index.html`: 빌드 도구 없이 바로 열 수 있는 학습 페이지 진입 파일
- `styles.css`: 반응형 레이아웃과 화면 스타일
- `app.js`: CBT 채점, 타이머, 번호판, 진도 저장, 강의 콘텐츠와 도면 렌더링
- `data/`: 2022년 제1회 문항·정답과 독립 작성 해설 데이터
- `app/`: 게시용 Sites/Next.js 진입 화면
- `tools/build-exam-data.ps1`: 공개 기출 문항·보기·정답만 다시 구조화하는 데이터 생성 도구

## 사용 방법

브라우저에서 `index.html` 파일을 열면 바로 사용할 수 있습니다.

학습 진도, 문제 풀이, 실기 체크리스트는 브라우저의 `localStorage`에 저장됩니다.

게시용 미리보기는 `pnpm install` 후 `pnpm run dev`, 최종 빌드는 `pnpm run build`로 생성합니다.
