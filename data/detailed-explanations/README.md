# 회차별 상세해설 데이터

각 파일은 `exam-archive.js`의 한 회차 100문항에 대응합니다.

```json
{
  "examId": "2534",
  "examDate": "2003-03-16",
  "explanations": {
    "1": {
      "explanation": "정답이 성립하는 실제 개념과 보기 구별 근거를 2~4문장으로 설명합니다.",
      "takeaway": "시험장에서 기억할 핵심을 한 줄로 정리합니다."
    }
  }
}
```

작성 기준:

- COMCBT 이용자 해설은 옮기지 않고 문항·정답을 바탕으로 독립 작성합니다.
- 정답 번호만 다시 말하거나 문제 유형만 설명하는 문장은 상세해설로 인정하지 않습니다.
- 부정형은 정답 보기가 왜 틀렸는지와 올바른 원칙을 함께 설명합니다.
- 계산형은 사용식, 대입 과정, 단위를 가능한 범위에서 적습니다.
- 법규형은 해당 회차의 출제 당시 기준임을 전제로 하며 현행 기준처럼 단정하지 않습니다.
- 오류 신고·복원 문항은 저장된 정답을 확정 사실로 만들지 않고 참고용임을 밝힙니다.
- 이미지 없이는 판단할 수 없는 문항은 보이지 않는 도형 세부를 지어내지 않습니다.
- `takeaway`는 개념·공식·대조쌍을 짧게 남깁니다.
